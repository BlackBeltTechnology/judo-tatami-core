# `src/main/java/hu/blackbelt/judo/tatami/core` — trace model, trace persistence, OSGi model trackers, log buffering

| File | Purpose |
|---|---|
| `AbstractModelPairTracker.java` | Joins two independently published OSGi model services into one name-keyed `(T1,T2)` pair so a transformation starts only when both halves are bound. Exports `openTracker(BundleContext)`, `closeTracker()`, abstract `install(T1,T2)`, `uninstall(T1,T2)`, `getModelClass1/2()`, `getModel1/2NameExtractorFunction()`. `install` fires from the T1 side only; `closeTracker()` closes `t2Tracker` twice and never `t1Tracker`. |
| `AbstractModelTracker.java` | Binds one OSGi model service type `T` and hands each instance to a transformation. Exports `openTracker(BundleContext)`, `closeTracker()`, `bindService`, `unbindService`, abstract `install(T)`, `uninstall(T)`, `getModelClass()`. Inner `ModelServiceTracker` filters on `getModelClass().getName()`; `closeTracker()` NPEs when `openTracker` never ran. |
| `AnsiColor.java` | Wraps log text in ANSI SGR escapes unless system property `disableJudoAnsiColors` is set. Exports `yellow(String)`, `red(String)`, `colorize(String,String)`. Colorized branch DISCARDS `str` and emits a literal slf4j `{}` placeholder — the caller must pass the value as a log argument. |
| `BufferedSlf4jLogger.java` | `Logger` + `Closeable` queueing `LogEntry(LogLevel,message,throwable)` instead of emitting, replayed by `flush()`, `sendToLogger()`, `sendToLogger(Logger)`; `close()` flushes. Level gate from `LogLevel.getMatchingLogLevels`. Formats with `String.format`, not slf4j `{}` — callers must use `%s`. `Marker` overloads drop the marker. |
| `CachingInputStream.java` | `BufferedInputStream` that marks at construction with `Integer.MAX_VALUE` and rewinds on `close()`, so one stream is re-readable by several loaders. Private `PostCloseProtection` returns -1/0 after the source closes. Whole stream buffers in memory; `close()` closes the source at most once. |
| `EMapWrapper.java` | Adapts EMF `EMap<K,V>` to `java.util.Map`. Lombok `@RequiredArgsConstructor` over `@NonNull EMap delegatee`. `remove(key)` reads the value before delegating so it returns the previous value, which `EMap.remove` does not. |
| `EtlTraceLoader.java` | `TraceLoader` for legacy Epsilon ETL XMI traces. StAX-reads `Trace` elements (`sourceUri` attribute, `targetUri` character children), writes them under namespace `http:///www.blackbelt.hu/meta/trasformation/trace/<ns>`. Resolves by URI fragment, then by an `id`-attribute index; unresolved URI throws `TraceLoadException`. DTD and external entities disabled. |
| `LogLevel.java` | Enum `ERROR|WARN|INFO|DEBUG|TRACE` with cumulative level sets. Exports `getMatchingLogLevels(LogLevel)` returning that level plus every coarser one, and `determinateLogLevel(Logger)` probing `isXEnabled()` from TRACE downward. Returns `INFO` when the logger reports no level enabled. |
| `PrettyPrinter.java` | Renders an `EObject` graph as indented text for logs. Exports `prettyPrint(EObject)`; recurses `getEAllStructuralFeatures()` with 4-space indent, printing `EClass` name plus canonical impl class. An already visited `EObject` prints its header with no children, so cyclic containment terminates. |
| `TraceEntry.java` | Immutable source→target mapping record. Lombok `@Builder`/`@Getter`, `@Singular` `sources`/`targets`, plus `ruleName`, `discriminator`, `primary`. Exports `getSource()`/`getTarget()` (first element or null), `hasMultipleSources()`, `hasMultipleTargets()`. `ruleName` and `discriminator` are null for traces coming from ETL. |
| `TraceFormat.java` | Enum selecting trace serialization: `ETL_XMI` (`.xmi`) or `ZETA_JSON` (`.json`). Exports `getFileExtension()`, `detect(String)`, `detectFromPath(Path)`, `detectFromUri(URI)`. Detection is lowercased-extension only; null or unknown input silently falls back to `ETL_XMI`. |
| `TraceLoadException.java` | Unchecked failure of `TraceLoader.loadTrace` — malformed trace data or an element reference no `ResourceSet` resolves. Extends `RuntimeException`; message, message+cause, cause constructors. Unchecked, so it never appears in a caller's `throws` clause despite being declared. |
| `TraceLoader.java` | SPI for one trace serialization format. Exports `loadTrace(InputStream, List<ResourceSet>)` and `saveTrace(List<TraceEntry>, OutputStream)`. Implementations resolve element references against the passed `ResourceSet`s, signal failure with `TraceLoadException`/`TraceSaveException`, and do not own the caller's stream. Implemented by `EtlTraceLoader` and `ZetaTraceLoader`. |
| `TraceSaveException.java` | Unchecked failure of `TraceLoader.saveTrace` — serialization or IO error while writing. Same three constructors as `TraceLoadException`. `EtlTraceLoader`/`ZetaTraceLoader` wrap the original exception as `cause` and prefix the message with the format name. |
| `TransformationMode.java` | Selects the transformation engine: `ETL` (Epsilon scripts), `ZETA` (Java), `DUAL` (runs both and compares output). Exports `fromSystemProperty()`, `isZeta()`, `isEtl()`, `isDual()`, `SYSTEM_PROPERTY = "judo.transformation.mode"`, `DEFAULT = ZETA`. Property value is trimmed and upper-cased; blank or unparsable yields `DEFAULT` silently. |
| `TransformationTrace.java` | Contract a transformation publishes as an OSGi service so its element mapping stays queryable. Exports `getSourceModelTypes()`, `getSourceModel/SourceResourceSet/SourceURI(Class)`, target counterparts, `getType()`, `getTransformationTraceName()`, `getModelName()`, `getModelVersion()`, `getTransformationTrace()`, and defaults `getTraceEntries()` / `getMultiSourceTransformationTrace()` derived through `TransformationTraceLoader`. `getModelName()` is the registry key that groups a trace chain. |
| `TransformationTraceLoader.java` | Static façade dispatching load/save to `EtlTraceLoader` or `ZetaTraceLoader` by `TraceFormat`, plus legacy/`@Deprecated` EMF pseudo-metamodel builders. → see `TransformationTraceLoader.AGENTS.md` |
| `TransformationTraceService.java` | Query API walking the registered trace chain of one model name upward and downward from a single `EObject`. → see `TransformationTraceService.AGENTS.md` |
| `TransformationTraceServiceImpl.java` | OSGi `@Component` implementing `TransformationTraceService` over a concurrent modelName→traces cache, with resource-fragment element identity. → see `TransformationTraceServiceImpl.AGENTS.md` |
| `TransformationTraceTracker.java` | OSGi `ServiceTracker<TransformationTrace,TransformationTrace>` feeding `TransformationTraceService.add`/`remove` on bind/unbind. Package-private constructor takes the service, `BundleContext`, and `TransformationTrace.class`. Caches the instance per `ServiceReference` so unbind reports the same object; references not assignable to the tracking bundle are ignored (`addingService` returns null). |
| `TransformationTraceTreeElement.java` | Wraps a `TransformationTrace` and adds parent links so a trace chain forms a DAG. Delegates every `TransformationTrace` method to `delegatee`. Exports `getDelegatee()`, `getParent()`, `setParent(List)`, `addParent(TransformationTraceTreeElement)`. Constructor is package-private; `parent` is a list, so one trace may have several parents. |
| `ZetaTraceLoader.java` | `TraceLoader` for the Zeta JSON trace format — accepts `source`/`sources` + `target`/`targets`, groups by identity-keyed `(source, ruleName, discriminator)`, flattens to source×target pairs on save. → see `ZetaTraceLoader.AGENTS.md` |
| `ZipUtil.java` | Zips files and directory trees into one archive. Exports `compressFiles(List<File> listFiles, String destZipFile)`. Directories are recursed with entry names relative to the top folder; loose files are entered by basename alone, so two same-named loose files collide. Copies through a 4096-byte buffer. |
