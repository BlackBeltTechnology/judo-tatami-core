# `src/main/java/hu/blackbelt/judo/tatami/core/workflow/flow` — composable flow nodes (sequence / parallel / conditional / repeat) that schedule `Work` and fold child `WorkReport`s

| File | Purpose |
|---|---|
| `AbstractWorkFlow.java` | Package-private base holding the flow name; exports only `getName()`. Constructor is package-private and stores the name unchecked, so a `null` name reaches every DEBUG log statement in the subclasses. Subclasses live in this package only — external code cannot add a flow type by extending it. |
| `ConditionalFlow.java` | Branching node: runs `toExecute`, applies `WorkReportPredicate` to its report, then runs `then(...)` on match or `otherwise(...)` on mismatch. Builder `aNewConditionalFlow()`, `named`, `execute`, `when`, `then`, `otherwise`, `build`. Returned report is the LAST executed work's, not `toExecute`'s. `otherwise` is skipped when unset or a `NoOpWork`. Builder defaults predicate to `ALWAYS_FALSE`. |
| `ParallelFlow.java` | Fan-out node; `call()` narrows the return type to `ParallelFlowReport`. Builder `aNewParallelFlow()`, `named`, `execute(Work...)`, `execute(Optional<Work>...)`, `execute(Stream<Optional<Work>>)` — empty `Optional`s are silently dropped, so a mistyped optional yields a smaller flow with no error. Each `build()` allocates its own `ParallelFlowExecutor`; report order does not follow submission order. |
| `ParallelFlowExecutor.java` | Package-private scheduler behind `ParallelFlow`. `executeInParallel(List<Work>)` submits every `Work` to an `Executors.newScheduledThreadPool(availableProcessors())`, busy-spins on `Future.isDone()` with no timeout, then `shutdown()`s and lazily re-creates the pool so the flow stays re-runnable inside a `RepeatFlow`. A never-returning work pins the caller forever. |
| `ParallelFlowReport.java` | Aggregate `WorkReport` over parallel children. Exports `getReports()`, `getStatus()`, `getError()`; `add`/`addAll` are package-private so only `ParallelFlow` populates it. `getStatus()` is `FAILED` when any child failed, else `COMPLETED` — an EMPTY report reads `COMPLETED`, and a `null` child status throws NPE. `getError()` surfaces only the first non-null error. |
| `RepeatFlow.java` | Loop node built on `do { work.call() } while (predicate.apply(report))` — work always runs at least once even when the predicate is false initially. Builder `aNewRepeatFlow()`, `named`, `repeat`, `times(int)` (delegates to `WorkReportPredicate.TimesPredicate.times`), `until`, `build`. A `FAILED` report is logged but does NOT break the loop. Returns last iteration's report. |
| `SequentialFlow.java` | Pipeline node running works in insertion order, breaking on the first report matching `WorkReportPredicate.FAILED`; later works are skipped. Builder `aNewSequentialFlow()`, `named`, `execute` (single/varargs/`Optional` varargs/`Stream`), `then`, `build` — `execute` and `then` both append. Empty list returns `new DefaultWorkReport(WorkStatus.COMPLETED)`; otherwise last executed report, i.e. the failing one. |
| `WorkFlow.java` | Marker interface extending `Work` and declaring nothing new. Because a flow IS a work, flows nest arbitrarily and any flow can be passed where a `Work` is expected; implementors inherit `call()` returning `WorkReport` and `getName()` and must satisfy the `Callable` contract of `Work`. |
