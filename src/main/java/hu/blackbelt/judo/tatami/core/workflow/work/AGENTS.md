# `src/main/java/hu/blackbelt/judo/tatami/core/workflow/work` — unit-of-work contract flows schedule: `Work`/`WorkReport`/`WorkStatus`, the transformation base class, and the shared `TransformationContext` blackboard

| File | Purpose |
|---|---|
| `AbstractTransformationWork.java` | Base every Tatami transformation step extends. Subclass implements `execute() throws Exception`; inherited `call()` wraps it into `DefaultWorkReport(COMPLETED)` or `DefaultWorkReport(FAILED, e)`, so a subclass must NOT swallow exceptions — they are the failure channel. Exports `getTransformationContext()`, `withMetricsCollector(MetricsCollector)`, `getName()` = FQCN + `" - "` + model name. |
| `DefaultWorkReport.java` | Concrete `WorkReport` carrying a `WorkStatus` and an optional `Throwable`. Exports `DefaultWorkReport(WorkStatus)`, `DefaultWorkReport(WorkStatus, Throwable)`, `getStatus()`, `getError()`, `toString()` rendering `error=''` when unset. Fields are set only at construction and never validated — a `null` status is accepted and later NPEs inside `WorkReportPredicate.COMPLETED`/`FAILED`. |
| `FailedWork.java` | Always-failing `Work` used to force a flow down its failure branch in tests and guard clauses. `call()` returns `new DefaultWorkReport(WorkStatus.FAILED)` with NO error attached, so `getError()` is `null` on the resulting report. `getName()` mints a fresh `UUID` per invocation, violating the stable-name expectation of `Work` — never key a lookup on it. |
| `MetricsCollector.java` | Timing sink `AbstractTransformationWork` calls around each step. Exports `invokedTransformation(String)` and `stoppedTransformation(String transformationName, long executionTime, boolean failed)`. Implementations receive `getClass().getSimpleName()` as the name (not the FQCN of `getName()`), elapsed time in NANOSECONDS, and are invoked from arbitrary parallel-flow threads — must be thread-safe. |
| `NoOpWork.java` | Always-succeeding `Work` used as the builder default for unconfigured flow branches (`ConditionalFlow` treats it as "no else branch"). `call()` returns `new DefaultWorkReport(WorkStatus.COMPLETED)`. `getName()` returns a new random `UUID` on every call, so identity-by-name does not hold. |
| `TransformationContext.java` | Blackboard passed between transformation steps; carries `modelName` (Lombok `@Getter`/`@Setter`) and a Guava `newConcurrentMap()` of variables. Exports `put(key, value)`, `put(value)` (keys by `value.getClass()`), `get(Object)`, `get(Class<T>, Object)` — throws `IllegalArgumentException` on type mismatch — `getByClass(Class<T>)`, plus inner `TransformationContextVerifier` field with `verifyClassPresent`/`verifyKeyPresent`. Writes are unordered: a step must not read a key a parallel sibling produces. |
| `Work.java` | Schedulable unit; extends `Callable<WorkReport>` and re-declares `call()` WITHOUT `throws`, so implementations must catch everything and report `WorkStatus.FAILED` rather than propagate. Also exports `getName()`, which must be unique within a workflow and must terminate in finite time — the parallel executor busy-waits with no timeout. |
| `WorkReport.java` | Result contract every flow folds over. Exports `getStatus()` and `getError()`. Implementations must return a non-null status (`ParallelFlowReport` and the `WorkReportPredicate` constants dereference it unguarded); `getError()` may be `null`, and a `FAILED` report is allowed to carry no throwable. |
| `WorkReportPredicate.java` | `@FunctionalInterface` deciding flow branching and loop exit via `apply(WorkReport)`. Constants `ALWAYS_TRUE`, `ALWAYS_FALSE`, `COMPLETED`, `FAILED` compare `workReport.getStatus()` — they NPE on a null report or null status. Nested `TimesPredicate.times(int)` returns `counter.incrementAndGet() != times` — TRUE until the n-th call, a continue-condition for `RepeatFlow`; it is stateful and must not be reused across flows. |
| `WorkStatus.java` | Two-valued outcome enum: `FAILED`, `COMPLETED`. No `SKIPPED`/`RUNNING` state exists, so a `SequentialFlow` abort is indistinguishable in status from works that never ran — callers infer skipping from the returned report identity, not from the enum. |
